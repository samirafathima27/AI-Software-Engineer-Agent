# AI Software Engineer Agent

An AI agent that can understand codebases, search code, debug issues, modify code, generate tests, run tests, and review changes.

## Current stage
Project structure initialized. We will build the system step by step.

## Initial stack
- Python
- LLM API
- Python AST / Tree-sitter
- Embeddings + vector database
- Tool calling
- LangGraph (later)
- pytest
- Streamlit (later)
- Git/GitHub
- Docker (later)
